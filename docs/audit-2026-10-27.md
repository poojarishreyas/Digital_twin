## Fixed during audit

Neo4j failed to start because its entrypoint attempted to change ownership of the read-only `init.cypher` bind mount. Removed that redundant mount from `docker-compose.yml`; `GraphStore.open()` already applies the same constraints and indexes. The stack then started and served ingestion and UI requests. The PRD's stale Qwen3.5-27B statement was updated to the current Qwen3.8-27B local profile and separate OmniRoute condition.

A later replay exposed three graph defects: topology omitted archetype nodes even while returning `INSTANCE_OF` edges; config edits retained stale archetype relationships; and delta envelopes retained old host-scoped structural edges. These are fixed and the replay now asserts valid archetype targets, current membership, and removal of a transient structural edge. Client certificates now carry distinct stable agent IDs, ingestion checks the envelope ID against the authenticated certificate, and the agent rejects certificate changes that conflict with its persisted ID. Go tests, all 49 Python tests, the UI build, and the expanded synthetic mTLS replay pass after these changes. Windows and Linux agent binaries were rebuilt with updated SHA-256 values in `bin/SHA256SUMS`.
